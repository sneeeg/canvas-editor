# Canvas Polygon Editor

Одностраничный редактор полигонов на Canvas, HTML, CSS и JavaScript.

## Возможности

- генерация случайных полигонов с 3-7 вершинами, случайным цветом и позицией;
- выделение полигона кликом внутри его области;
- перетаскивание выбранного полигона с ограничением по границам canvas;
- запрет наложения полигонов друг на друга при генерации и перемещении;
- удаление выбранного полигона, удаление всех полигонов;
- Undo/Redo для генерации, удаления, перемещения и изменения цвета;
- горячие клавиши: `Ctrl+Z`, `Ctrl+Y`, `Ctrl+Shift+Z`, `Delete`;
- информационная панель с количеством фигур и текущим выбранным полигоном;
- изменение цвета выбранного полигона;
- экспорт и импорт сцены в JSON.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:3000`.

## Сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.
